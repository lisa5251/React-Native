# Restaurant Management System - Code Reference

This folder contains all the starter code snippets for your final project. Use these files as a reference guide when building your app.

## File Structure

```
CODE_REFERENCE/
├── 1_AuthContext.js        → Global state for user login
├── 2_OrderContext.js       → Global state for all orders
├── 3_authService.js        → Login/logout functions
├── 4_orderService.js       → Order operations
├── 5_CustomButton.js       → Reusable button component
├── 6_MenuItemCard.js       → Menu item card component
├── 7_OrderCard.js          → Order card component
├── 8_LoginScreen.js        → Waiter login screen
└── README.md              → This file
```

## How to Use

1. Open each file in this folder
2. Copy the code
3. Paste it into your `finalproject/src/` folder in the corresponding location
4. Make sure you understand each line before moving to the next piece
